# 🚆 Seccional Retiro | Sitio Web Institucional

**Prototipo de sitio web informativo para la Seccional Retiro de la Unión Ferroviaria.**

Una propuesta de desarrollo web orientada a facilitar el acceso a información institucional, beneficios, formularios y servicios para las compañeras y compañeros ferroviarios.

---

## 📌 Sobre el proyecto

Este proyecto surge con el objetivo de centralizar información de consulta frecuente en un sitio web sencillo, accesible y adaptable a dispositivos móviles.

Está pensado como un punto de acceso desde las redes sociales de la Seccional, permitiendo que las personas encuentren la información que necesitan sin tener que buscar entre distintas publicaciones.

El sitio tiene una finalidad informativa y no reemplaza los canales oficiales de atención ni los procedimientos administrativos existentes.

## 🧭 Secciones principales

| Sección | Descripción |
|---|---|
| **Afiliación y empadronamiento** | Información, requisitos y formularios para realizar ambos trámites. |
| **Beneficios** | Consulta de beneficios, condiciones, documentación necesaria y formularios asociados. |
| **Turismo** | Información sobre alojamientos, fotografías y documentación relacionada. |
| **Formularios** | Catálogo de formularios descargables con buscador para facilitar su localización. |
| **Newsletters** | Acceso a la última edición y al archivo de publicaciones anteriores. |
| **Oficinas sindicales** | Ubicación de las oficinas sindicales mediante mapas integrados. |

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura y organización del contenido.
- **CSS3:** diseño visual, estilos reutilizables y adaptación a diferentes pantallas.
- **JavaScript:** búsqueda y filtrado de formularios.

El proyecto está desarrollado sin frameworks, priorizando una implementación sencilla y fácil de mantener.

## ✨ Características

- Diseño responsive, con prioridad para dispositivos móviles.
- Navegación mediante tarjetas organizadas por categorías.
- Acceso a formularios y documentos PDF.
- Buscador de formularios.
- Galerías de fotos de los alojamientos turísticos.
- Visualización de newsletters.
- Mapas integrados para consultar las ubicaciones de las oficinas.
- Navegación mediante teclado.

## 🚧 Estado del proyecto

## 🔄 Mantenimiento y evolución

El proyecto contempla la actualización periódica de información, formularios, importes y publicaciones.

Como posible evolución, se prevé incorporar un mecanismo de administración de contenidos con revisión y aprobación previa de las modificaciones.

Estas funcionalidades administrativas todavía no forman parte del prototipo actual.
